# المرحلة ١٢ — Landing + SEO + Legal (اكتملت)

> هذه هي المرحلة الحادية عشرة بخطة ترقيم كتاب «أوج — خطة التطوير والتنظيف حتى النشر»
> (صفحة «المرحلة الحادية عشرة — Landing + SEO + Legal»)، وتُعرَّف داخل الريبو بمجلد
> `docs/phase-11/` اتساقًا مع ترقيم مجلدات المراحل السابقة (phase-N = مرحلة N+1 في الخطة).

## ما كان قائمًا قبل المرحلة
- صفحة هبوط تسويقية كاملة (`landing.tsx`) بخلفية OG عربية — بلا قسم أسعار ولا روابط قانونية.
- `public/robots.txt` ثابت بسيط بلا Sitemap.
- بلا صفحات قانونية، بلا sitemap.xml، بلا بيانات منظمة، بلا canonical.

## ما أُنجز في هذه المرحلة

### صفحات عامة جديدة (كلها Server Components خالصة)
| المسار | الغرض |
|---|---|
| `/pricing` | الباقات الثلاث (المجانية/بلس ٣٠ج/ماكس ٥٠ج) + أسئلة الدفع + JSON-LD (Product+Offers) |
| `/privacy` | سياسة الخصوصية الكاملة مبنية على ما ينفذه الموقع فعليًا (RLS، AdSense للـFree فقط، تصدير/حذف ذاتي) |
| `/terms` | شروط الاستخدام: الباقات، الدفع اليدوي، الاستخدام العادل، شروط MCP لماكس، القانون المصري |
| `/community-guidelines` | إرشادات المجتمع + تدرج إجراءات الإشراف المتوافق مع أدوات moderation الموجودة |
| `/refund-policy` | الاسترجاع خلال ٤٨ ساعة + الإلغاء الذاتي + ما يحدث للبيانات عند انتهاء الاشتراك |
| `/contact` | قنوات التواصل (دعم/فوترة/أمان/تجاري) مع أزمنة رد معلنة |
| `/about` | قصة المنتج ومبادئه (عربي أولًا، دون إنترنت، خصوصية، MCP) |

### SEO
- `src/app/sitemap.ts` — خريطة تلقائية لكل الصفحات العامة (تستثني `/app` و`/api` و`/mcp` و`/reset-password`).
- `src/app/robots.ts` — يستبدل `public/robots.txt` الثابت: قواعد زحف + ربط sitemap (مع حذف الملف الثابت).
- `src/lib/site.ts` — مصدر واحد لعنوان الموقع (`NEXT_PUBLIC_SITE_URL` من البيئة، افتراضي `https://awj.life`) وعناوين البريد والباقات.
- JSON-LD على الرئيسية: `SoftwareApplication` (مع الـ3 عروض أسعار) + `Organization` + `FAQPage` (من نفس مصدر أسئلة اللاندنج — بلا ازدواج).
- canonical لكل صفحة عامة + بطاقة Twitter (summary_large_image) + صورة OG فعلية.
- `public/og.png` (1200×630) — بطاقة مشاركة مولّدة بهوية أوج (نافورة أورورا زمردية على كحلي داكن + «أوج» بخط El Messiri + الشعار بخط Tajawal) — نسخة معاينة محفوظة في `download/awj-og-preview.png` محليًا.

### تحديثات اللاندنج (`landing.tsx`)
- قسم أسعار جديد `#pricing` بثلاث بطاقات (ماكس مميزة بحد زمرد) — نفس محتوى صفحة `/pricing`.
- رابط «الأسعار» في شريط التنقل.
- التذييل: روابط (عن أوج/تواصل) + شريط قانوني ثانٍ (خصوصية/شروط/إرشادات/استرجاع).
- `FAQS` أصبحت `export` لتغذية JSON-LD من نفس المصدر.

## قرار معماري واحد يستحق التوثيق
الدومين المرجعي لكل الـSEO هو `awj.life` (افتراضي `metadataBase` الموجود أصلًا). عند الرغبة في
فهرسة دومين آخر قبل تثبيت awj.life: اضبط `NEXT_PUBLIC_SITE_URL` في Vercel — `sitemap.ts`
و`robots.ts` و`siteUrl()` تتبعه تلقائيًا، وcanonical/OG يُبنَيان على `metadataBase` ذاته.

## متبقٍّ على المالك (خارج الكود)
1. تثبيت دومين awj.life على Vercel عند الجاهزية (أو ضبط `NEXT_PUBLIC_SITE_URL` للدومين المؤقت).
2. ربط Google Search Console والتحقق بالملكية.
3. بريد الدعم `support@awj.life` و`business@awj.life`: إنشاء الصناديق أو إعادة توجيهها لبريد فعلي.
4. مراجعة نصوص الصفحات القانونية قبل الإطلاق العام — كُتبت لتطابق الواقع التقني الحالي (دفع يدوي، MCP لماكس…) لكن مراجعة بشرية نهائية مسؤولية المالك.

## فحوصات
- `deno check`/`tsc`: كل الملفات الجافة Server Components بلا hooks، والأنواع مطابقة لـ`Metadata` من `next`.
- صيغ JSON-LD مبنية على أمثلة Schema.org القياسية (Product/SoftwareApplication/FAQPage/Organization).
- روابط داخلية كلها Server Navigation (`<a>`) — لا تكسر CSP/nonce الخاص بالـPWA.
