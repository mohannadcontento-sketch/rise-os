# أوج (Awj) — Design System
### المرحلة الثانية (الترتيب 03/18) — تأسيس Design System وهوية أوج
**التاريخ:** 12 سبتمبر 2026 · **الحالة:** معتمد وموثّق

---

## 1. الهوية

| العنصر | القيمة |
|--------|--------|
| **الاسم النصي** | أوج |
| **عنوان المنتج** | awj.life |
| **الشعار (Logo mark)** | «الشمس في أوجها» — شمس متوهجة تعتلي قمة جبل (`public/icon.svg`) |
| **الوصف المختصر** | نظام حياتك الشخصي |
| **التاغلاين** | «امتلك صباحك. امتلك حياتك.» |
| **ألوان العلامة** | أوبسيديان `#070B14` → غابة `#1B342B` + شمس ليمونية `#D6FF3D` + قمة كريمية `#F2F5F7` |

**قاعدة الاسم:** كل نص يظهر للمستخدم (واجهة، عنوان صفحة، manifest، PWA، إشعارات، تصدير، رسائل نظام) يستخدم «أوج». المعرفات الداخلية للكود (`/api/rise/*`، `components/rise/`، `useRiseStore`) بقيت كما هي عمدًا — تغييرها كسر بلا قيمة بصرية.

## 2. Typography (الخطوط)

| الرمز | الخط | الاستخدام |
|-------|------|-----------|
| `--font-sans` | `Inter → Tajawal → system-ui` | النصوص الأساسية (Inter للأرقام واللاتيني، Tajawal يكمل الحروف العربية حرفًا بحرف) |
| `--font-display` | `El Messiri → Tajawal → Inter` | العناوين ولحظات البطل (Hero) — يستخدم باعتدال |
| `--font-mono` | `ui-monospace, SF Mono…` | الأكواد والأرقام الجدولية |

**السلّم:** 10px (pills) · 12px (ثانوي) · 13-14px (أساسي) · 16-18px (عناوين فرعية) · 20-24px (عناوين) · 32px+ (Hero). أوزان: 400 / 500 / 700 / 800 (bold للعناوين، 700 للـ pills).

## 3. Radius (الاستدارة)

`--radius: 1rem` أساس، والمشتقات: `sm = −4px` · `md = −2px` · `lg = 1rem` · `xl = +4px` · `2xl = +8px` · `99rem` (pills والدوائر الكاملة).

## 4. Shadow & Depth (الظلال)

| الرمز | الوضع النهاري | الوضع الليلي |
|-------|----------------|----------------|
| `--tile-shadow` | ظل ورقي ناعم ثنائي الطبقة | ظل عميق ثلاثي الطبقات |
| `--tile-shadow-hover` | ظل مرتفع عند التحويم | + توهج ليموني |
| `--glow` | معطّل (شفافية صفرية — الورق لا يتوهج) | توهج ليموني مزدوج النطاق |
| `--glow-violet` | معطّل | توهج بنفسجي (لحظات AI/التركيز) |

**قاعدة:** النهار = ورق وضوء طبيعي (ظلال فقط). الليل = أوبسيديان وأورورا (توهجات). لا يوجد توهج في الوضع النهاري إطلاقًا.

## 5. Breakpoints (نقاط التوقف)

Tailwind الافتراضية كما هي: `sm 640px` · `md 768px` · `lg 1024px` (تبديل Sidebar/GlassNav) · `xl 1280px` · `2xl 1536px`. القاعدة الحرجة: شريط التنقل الزجاجي السفلي `lg:hidden`، والشريط الجانبي من `lg` فأعلى.

## 6. Spacing

مقياس Tailwind الافتراضي (0.25rem أساس) — بلا تخصيص. الحشوات المعيارية: صفوف القوائم `py-[7px]`، بطاقات الوحدات `p-4`، حول العناوين `mb-4 sm:mb-6`، حاشية المحتوى `p-3 sm:p-4 md:p-6 pb-28 lg:pb-6` (الحشوة السفلية للموبايل تترك مجالًا للشريط الزجاجي).

## 7. نظام الألوان (Design Tokens)

مصدر الحقيقة الوحيد: `src/app/globals.css` (Tailwind v4 CSS-first عبر `@theme inline`). الوضعان عالمان مختلفان — ليس مجرد تخفيت:

| الرمز | Dawn Paper (نهاري) | Obsidian Aurora (ليلي) |
|-------|--------------------|------------------------|
| `--background` | `#F4F2EA` ورق دافئ | `#070B14` أوبسيديان |
| `--foreground` | `#0B1015` حبر | `#F2F5F7` ضوء بارد |
| `--primary` | `#1B342B` غابة | `#D6FF3D` ليموني |
| `--accent` | `#D6FF3D` ليموني | `#D6FF3D` ليموني |
| `--card` | `#FFFFFF` | `#0E1626` |
| `--border` | `#DDD7C6` | `#1D2B47` |
| `--muted` | `#EFEDE4` | `#121B2E` |
| `--destructive` | `#DC2626` | `#FF7A8C` |

أيقونات الوحدات (hue system): `lime / blue / violet / rose / amber / forest / cyan` — أباريق لونية عبر `MODULE_ICONS` مع آبار أيقونات `iw-*` موحدة.

## 8. حالات النجاح/التحذير/الخطأ/المعلومات (موحّدة في هذه المرحلة)

رموز دلالية جديدة (AA مُتحقق في الوضعين) — تُستخدم بدل أي لون خام:

| الرمز | نهاري | ليلي |
|-------|-------|------|
| `--success` / `*-foreground` | `#15803D` / `#FFFFFF` | `#4ADE80` / `#052E16` |
| `--warning` / `*-foreground` | `#B45309` / `#FFFFFF` | `#FBBF24` / `#422006` |
| `--info` / `*-foreground` | `#1D4ED8` / `#FFFFFF` | `#7FB8FF` / `#0A1B3D` |
| `--destructive` (خطأ) | `#DC2626` | `#FF7A8C` |

**الاستخدام:** `text-success`, `bg-warning/15`, `border-info`… عبر تسجيل `--color-*` في `@theme inline`. الـ pills الجاهزة: `.pill-success / .pill-warning / .pill-info / .pill-error / .pill-muted / .pill-lime` — تعمل تلقائيًا في الوضعين عبر `color-mix` (لا حاجة لقواعد `.dark` منفصلة).

**الإشعارات اللحظية (Toasts):** نظام وحيد — **sonner** (`richColors`, top-center) عبر مساعدات `src/lib/toast-helpers.ts` (`toastSaved/toastCreated/toastDeleted/toastError`). حُذف نظام toast القديم (`ui/toast`, `ui/toaster`, `hooks/use-toast`) نهائيًا.

## 9. التنقل وDashboard Shell (موحّد)

| السطح | المكوّن | ملاحظة |
|-------|---------|--------|
| سطح المكتب | `sidebar.tsx` — 4 مجموعات أكورديون + لوحة مثبتة + إعدادات | أيقونات من `MODULE_ICONS` |
| الموبايل | `glass-nav.tsx` — 5 عناصر زجاجية سفلية | نفس الأيقونات والرموز |
| عنوان الصفحة | `moduleNames` في الـ shell | — |

**المصدر الوحيد للتسميات:** `src/lib/module-labels.ts` (`MODULE_LABELS`) — يغذي الثلاثة أعلاه. قبل التوحيد كان للوحة التحكم اسمان (الرئيسية في الموبايل / لوحة التحكم في الديسكتوب) — دُمج في «لوحة التحكم».

**زر الخروج:** تأكيد `AlertDialog` قبل تنفيذ الخروج — لا خروج فوريًا بضغطة واحدة بعد اليوم.

## 10. Dark / Light

`next-themes` (`attribute="class"`, `defaultTheme="system"`, `enableSystem`) + مفتاح ThemeToggle متحرك (شمس/قمر) في رأس التطبيق. سكربت التهيئة Inline محمي بـ CSP nonce من الـ middleware. **لا إعادة تصميم** — السلوك القائم كان سليمًا واعتُمد كما هو.

## 11. قواعد صارمة (DoD الحارسة)

1. لا ألوان خام (`green-600`, `amber-500`…) في الحالات الدلالية — الرموز فقط. (الشمس داخل مفتاح الثيم استثناء مقصود: لون تمثيلي للشمس لا حالة تحذير).
2. لا `label` مكرر لموديول واحد — `MODULE_LABELS` فقط.
3. لا نظام toast ثانٍ — sonner فقط.
4. الوسم الظاهر للمستخدم = «أوج» دائمًا.
5. أي حالة نجاح/تحذير/خطأ/معلومات جديدة تبدأ من الرموز الدلالية لا من لوحة الألوان الخام.
