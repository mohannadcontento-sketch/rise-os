## 2. الأمان (بنود الخطة «Data / Security»)

- **فصل البيانات**: جداول المجتمع لا تحمل سوى `user_id` + معلومات العرض العامة (الاسم/handle/الصورة عبر RPC بصلاحيات موسّعة) — لا بريد ولا بيانات خاصة.
- **Ownership**: سياسات RLS — select (published أو صفك) / insert-own / update-own-published / delete-own. المحتوى المخفي يظهر لصاحبه فقط.
- **منع تزوير العدادات**: إذونات على مستوى **الأعمدة** — المستخدم يستطيع كتابة أعمدة المحتوى فقط (`title/body/edited_at`)؛ حتى نداء PostgREST مباشرة لا يستطيع تعيين `like_count`/`reply_count`/`status`. (اكتشفنا أثناء الاختبار أن Supabase default-ACL يمنح كل الصلاحيات تلقائيًا — سحبناها صراحة من `authenticated`).
- **Anti-spam**: rate limits في الـmiddleware (نشر 30/دقيقة، تعليقات 30، تفاعل 60، بلاغات 5) + قيود فريدة (تفاعل واحد/مستخدم/هدف، بلاغ واحد/مستخدم/هدف) + سقوف طول + dedup للإشعارات + حد 20 ذِكرًا للمحتوى الواحد.
- **سجل الإشراف**: كل إجراء يُقيَّد في `community_moderation_log` (قراءة/كتابة service_role فقط) + يُخطر المتأثر بإشعار عالي الأولوية.

## 3. الإشعارات (ربط الحدث الموحد)

| الحدث | النوع | لمن | dedup key |
|---|---|---|---|
| تعليق على منشوري | `community` | صاحب المنشور | `community-comment-<id>` |
| رد على تعليقي | `community` | صاحب التعليق الأب | `community-reply-<id>` |
| ذِكر في منشور/تعليق | `mention` (عالي) | المذكور | `mention-<source>-<id>-<uid>` |
| إخفاء/إزالة محتواي | `system` (عالي) | صاحب المحتوى | `mod-<action>-<id>` |
| حظر/فك حظر | `system` (عالي) | المستخدم | `mod-(un)ban-<uid>-<ts>` |

الإعجاب لا يولّد إشعارًا (قرار موثّق — مضاد للإزعاج). الأنواع `community`/`mention` كانت جاهزة منذ الهجرة 026 (CHECK + بوابة Push قسمتهما لفئة community)، فالـ Web Push يعمل لهذه الأحداث تلقائيًا لمن فعّل فئة المجتمع.

## 4. واجهة الاستخدام

- **وحدة «المجتمع»** في التطبيق (شريط جانبي + تنقل + بحث الأوامر): خلاصة بفلاتر، كومبوزر مع اقتراحات @mention منبثقة، تفاصيل منشور بتعليقات وردود، قلب toggle، بلاغ بحوار، تعديل/حذف ذاتي، **تحميل تدريجي** (IntersectionObserver + زر «المزيد») مع skeletons.
- **إشعار → منشور**: `actionUrl = community?post=<id>` — معالج التنقل يفتح الوحدة ويستهلك المعرّف عبر `community-focus` (يحل توقيت التركيب).
- **تاب «المجتمع»** في لوحة الإدارة: طابور البلاغات بمعاينة المحتوى + إجراءات (إخفاء/إزالة/استبعاد/حظر صاحبه) بقوارص تأكيد وسبب + قائمة المحظورين + آخر 100 إجراء إشراف.

## 7. ملاحظة Turso

الخطة ذكرت «جداول المجتمع العامة إلى Turso» — المشروع استقر منذ البداية على Supabase Postgres كقاعدة وحيدة (قرار معماري موثّق في المراحل السابقة)، فجداول المجتمع في `public` بنفس الفصل المنطقي: لا بيانات خاصة داخل جداول المجتمع، وRLS + إذونات الأعمدة تحكم الوصول. لو قرر المالك لاحقًا فصل قاعدة المجتمع، البنية (RPC-only reads + service-writes) جاهزة للنقل.
