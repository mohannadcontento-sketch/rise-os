# English Kids Quest

لعبة ويب تفاعلية للأطفال لتعلّم نطق الحروف الإنجليزية و50 جملة أساسية. تتضمن ملفات الصوت والرسوم محليًا، لذلك تعمل أزرار الاستماع داخل النسخة المستقلة من المستودع.

## التشغيل المحلي

```bash
cd apps/english-kids-quest
pnpm install
pnpm dev
```

افتح العنوان الذي يعرضه Vite في المتصفح.

## تدريب النطق

ميزة **قلها معي** تستخدم واجهة التعرف الصوتي المدمجة في المتصفح، وتعمل بصورة أفضل في Chrome وEdge مع السماح بالوصول إلى الميكروفون. تتم مطابقة النص الذي تعرّف عليه المتصفح مع الكلمة المستهدفة فقط؛ لا تحفظ اللعبة أي تسجيل صوتي. هذه ميزة تدريب مشجعة وليست تقييمًا صوتيًا احترافيًا أو تشخيصًا للنطق.

## الفحوص

```bash
pnpm run check
pnpm run build
```
